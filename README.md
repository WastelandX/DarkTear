## 📖 About DarkTear

DarkTear is a phishing framework designed for:

- Security professionals conducting authorized penetration tests
- Researchers studying social engineering techniques
- Educational demonstrations in controlled environments

It features:

- 🎨 **Custom tri-color logo** (Red, Electric Blue, Orange)
- 📄 **26 pre-built phishing pages** (Facebook, Instagram, Gmail, Netflix, PayPal, GitHub, Roblox, and more)
- 🚇 **Manual tunnel support** (localhost.run, LocalXpose, Ngrok, etc.)
- 📝 **Credential logging** with automatic folder creation
- 🧪 **Fake credential detection** (separates real from test data)
- 📱 **Mobile-responsive HTML templates**
- 🖥️ **Clean terminal interface** with dark blue tunnel logo
